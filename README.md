## 📌 Description & Overview

Système de gestion locale pour commerce (tickets, caisse, paye, crédits), stockage 100% navigateur (IndexedDB) et export Excel. Déployé en production avec un service Windows auto-résilient.

This project is an interactive engineering module built by **DJIDEL Abdelali Rayan** (Systems & Automation Engineer).
